> **Sonarrr is not Sonarr.** Sonarrr ([sonarrr.app](https://sonarrr.app)) is a legal streaming guide for films and series. It is not the PVR software Sonarr ([sonarr.tv](https://sonarr.tv)), and there is no affiliation between the two.

## What Sonarrr is

Sonarrr helps people choose a film or a series and see where it can be streamed legally. The site does not stream or host any titles: playback links open the relevant platform, under that platform’s own subscriptions and terms.

The default version of the site is in French at [https://sonarrr.app](https://sonarrr.app). An English version is at [https://sonarrr.app/en](https://sonarrr.app/en). Other language versions that are live on the site are linked in the sections below.

Sonarrr is published by Lucas Bolivard EI. Contact: [bonjour@sonarrr.app](mailto:bonjour@sonarrr.app).

## Public MCP server

Sonarrr provides a public, read-only MCP server (no authentication). Assistants can use it to search films and series, look up streaming availability for a title, and get a franchise watch order.

The documented tools are `search_titles`, `get_title_streaming` and `get_universe_watch_order`.

- Discovery manifest: [https://sonarrr.app/.well-known/mcp.json](https://sonarrr.app/.well-known/mcp.json)
- Endpoint: [https://sonarrr.app/api/mcp](https://sonarrr.app/api/mcp)
